# Telegram AI Finance Tracker (Laravel + WordPress Sync)

An AI-powered Telegram bot that tracks income and expenses using natural language.  
Built with Laravel backend, Gemini AI parsing, and WordPress synchronization.

---

## 🚀 Features

- 📲 Telegram Bot interface
- 🧠 AI-powered message parsing (Gemini API)
- 💰 Income & Expense tracking
- 📊 Finance summary queries (daily, weekly, total)
- 🔄 WordPress database synchronization
- 🗃️ Dual database storage (Laravel + WordPress)
- 🧾 Structured transaction logging
